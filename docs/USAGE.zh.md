# 技能菜单 · 中文使用说明书

适用版本：0.2.0 ｜ 插件名：`@qiejianchuangyi/dsh-skill-menu` ｜ [English](USAGE.en.md)

---

## 1. 它长什么样

输入框下方那排小按钮的左侧，多出一个写着 `skill` 的按钮，位置在表情包按钮右边、`优化` 左边。

```
[ + ] [ 完全权限 ] [ 标准 ] [ 😊 ] [ skill ] ............ [ 优化 ] [ 发送 ]
```

点一下它，输入框上方浮出「技能库」面板。

## 2. 面板结构

```
┌──────────────────────────────────────────────┐
│ 技能库   43 个可用        推荐  名称  最近  关闭 │
│ ┌──────────────────────────────────────────┐ │
│ │ 搜技能名或用途，例如 PPT、论文、表格        │ │
│ └──────────────────────────────────────────┘ │
│  常用                       大多数人先看这些   │
│  dsh-doc                          自定义  置顶 │
│  查 DSH 自身功能与用法                          │
│  不懂某个设置或插件时                           │
│  …                                            │
│  悬停看说明 · 点击直接调用   中文说明 43/43 清空记录 │
└──────────────────────────────────────────────┘
```

- **标题行**：`技能库` + 可用数量 + 三档排序 + `关闭`。
- **搜索框**：输入即过滤。
- **列表**：按当前排序分区显示，每行三层文案（名字 / 做什么 / 什么时候用），右侧是来源标签。
- **页脚**：操作提示、中文说明覆盖率、`清空记录`。

## 3. 排序与分区

| 档位 | 首屏长什么样 | 适合场景 |
| --- | --- | --- |
| **推荐**（默认） | 置顶 → 最近使用 → 常用（前 10 个，权重 ≥ 70）→ 六个分类 | 日常使用，多数人只看前两屏 |
| **名称** | 全部技能按字母序扁平排列 | 明确记得名字时快速定位 |
| **最近** | 按本机使用次数从多到少 | 最近反复用的那几个 |

分类固定六类：文档办公 / 写作表达 / 研究检索 / 设计排版 / 开发排查 / 其他。

排序偏好会记住（`localStorage` 键 `dshsm.sort`），下次打开沿用。

## 4. 搜索

在搜索框输入关键词，面板切换成扁平的「搜索结果」，匹配三处：

1. skill 名（`office`、`nature-`）；
2. 中文一句话作用（`论文`、`PPT`、`修复 ACL`）；
3. 分类名（`设计排版`、`开发排查`）。

例：输入 `PPT` → office-pptx、guizang-ppt-skill、nature-paper2ppt、nature-image2ppt。

清空搜索框回到原排序。

## 5. 悬停看中文说明

鼠标停在任意一行约 0.28 秒，面板左侧（放不下时右侧）浮出说明框，内容四段：

```
office-pptx
做 / 改 PPT 演示文稿
什么时候用
  · 汇报、培训、路演
  · 已有大纲要变成可编辑幻灯片
需要什么 · 得到什么
  大纲或要点 → 可编辑的 .pptx 文件
```

- 行内还会出现 `置顶` 按钮（最多 5 个）。
- 说明框不挡点击，鼠标移开自动消失。
- 未收录中文说明的 skill 直接显示它自带的英文 `description`，并在末尾标注「暂未收录中文说明」。

## 6. 点击调用

点任意一行（或选中后按 `Enter`）：

1. 面板收起；
2. 输入框写入 `使用 skill「<name>」`，已有草稿保留在下一行；
3. 立即发送（`AUTO_SEND = true`）；
4. Agent 收到后调用同名 skill。

想让它只填入、不自动发送：把 `client.js` 顶部的 `AUTO_SEND` 改成 `false`，刷新页面。这时点一行只是填好文本，你自己按回车。

## 7. 键盘操作

| 键 | 作用 |
| --- | --- |
| `↑` / `↓` | 在可见列表里上下选行 |
| `Enter` | 执行选中的行 |
| `Esc` | 关闭面板 |

面板打开时点击面板外任意位置也会关闭。

## 8. 使用记录与置顶

- 每次点击调用记一次使用数（`localStorage` 键 `dshsm.usage`），用于「最近使用」和「常用」。
- 置顶列表存 `dshsm.pins`，最多 5 个，点行内 `置顶` 切换。
- 页脚 `清空记录` 清掉使用数（置顶保留，需手动取消）。
- 换机器、换浏览器配置、清缓存后记录即丢，属于预期行为。

## 9. 配置项

在 `client.js` 顶部，改完刷新页面（`Ctrl+R`）生效：

| 常量 | 默认值 | 说明 |
| --- | --- | --- |
| `AUTO_SEND` | `true` | 点一行后是否自动发送 |
| `PANEL_W` | `380` | 面板宽度（CSS 像素），窄屏自动收窄 |
| `TIP_W` | `330` | 悬停说明框宽度 |
| `COMMON_MIN_WEIGHT` | `70` | 「常用」分区的权重阈值 |
| `COMMON_LIMIT` | `10` | 「常用」最多几条 |
| `RECENT_LIMIT` | `5` | 「最近使用」最多几条 |
| `PIN_LIMIT` | `5` | 置顶上限 |
| `TIP_SHOW_DELAY` | `280` | 悬停多久显示说明（毫秒） |
| `TIP_HIDE_DELAY` | `140` | 移开后多久隐藏（毫秒） |

## 10. 给新 skill 补中文说明

1. 打开 `client.js`，找到 `CATALOG`；
2. 按名字加一条：

```js
'your-skill-name': {
  cat: 'doc',            // doc/write/research/design/dev/other
  weight: 80,            // ≥70 会进「常用」
  short: '一句话说做什么',
  scene: '什么时候用',
  when: ['触发场景一', '触发场景二'],
  io: '需要什么 · 得到什么',
},
```

3. 刷新页面，页脚的覆盖率会从 `43/43` 变成 `44/44`。

## 11. 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 输入框旁没有 `skill` 按钮 | 插件未启用：插件页确认 `dsh-skill-menu` 已开启；或装载失败看 DSH 日志；勾选后刷新页面 |
| 面板打开但一直是「加载中…」 | 宿主路由不通：`curl http://127.0.0.1:<端口>/dsh-skill-menu/list` 手工试；端口在 DSH 设置里查 |
| 列表数量比预期少 | 只列 `userInvocable: true` 的 skill；换了会话（Agent 作用域不同）数量会不同 |
| 悬停没有说明 | 说明框显示延迟 0.28 秒，稍等；或用键盘选中后看行内文字 |
| 点击后没反应 | `AUTO_SEND=false` 时只会填文本；检查输入框是否只读；看控制台是否报 `inputActions` 不可用 |
| 点「置顶」没变化 | 置顶上限 5 个，先取消一个 |
| 数量与 `curl` 不一致 | 面板缓存了上次结果，关掉面板再打开即重新拉取 |

## 12. 隐私与安全

- 列表数据只来自本机 DSH 进程，插件不发任何外网请求。
- 数据路由 `/dsh-skill-menu/list` 只接受 `127.0.0.1` / `::1` 的回环请求，其他来源返回 403；仅 GET。
- 插件只读 skill 的名称与说明，不读取、不修改 skill 文件。
- 使用记录存在本机浏览器 `localStorage`，不上传。
